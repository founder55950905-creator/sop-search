/** * NG回報系統 - Google Apps Script 後端 * 功能:接收作業員回報的料號、製程、異常類型、備註、照片 * 將資料寫入 Google Sheet,照片存進 Google 雲端硬碟並取得連結 * * 使用方式: * 1. 這支程式要貼在「NG回報紀錄」這張 Google Sheet 綁定的 Apps Script 裡 * 2. 部署為 Web應用程式,執行身份選「我」,存取權限選「任何人」 * 3. 部署後取得的網址,提供給前端查詢工具使用 */ function doPost(e) { try { const data = JSON.parse(e.postData.contents); const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('NG回報紀錄'); // 處理照片:將 base64 圖片存到雲端硬碟指定資料夾 let photoUrl = ''; if (data.photoBase64 && data.photoBase64.length > 0) { const folderName = 'NG回報照片'; let folder; const folders = DriveApp.getFoldersByName(folderName); if (folders.hasNext()) { folder = folders.next(); } else { folder = DriveApp.createFolder(folderName); } // 從 data URL 中取出純 base64 內容與檔案類型 const matches = data.photoBase64.match(/^data:(image\/\w+);base64,(.+)$/); if (matches) { const mimeType = matches[1]; const base64Data = matches[2]; const blob = Utilities.newBlob( Utilities.base64Decode(base64Data), mimeType, `NG_${data.matCode || 'unknown'}_${new Date().getTime()}.jpg` ); const file = folder.createFile(blob); // 設定為「知道連結的人可檢視」,方便之後從Sheet直接點連結看照片 file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW); photoUrl = file.getUrl(); } } // 寫入一列新資料到 Sheet sheet.appendRow([ new Date(), data.matCode || '', data.process || '', data.ngType || '', data.note || '', photoUrl ]); return ContentService .createTextOutput(JSON.stringify({ result: 'success' })) .setMimeType(ContentService.MimeType.JSON); } catch (error) { return ContentService .createTextOutput(JSON.stringify({ result: 'error', message: error.toString() })) .setMimeType(ContentService.MimeType.JSON); } } // 測試用:確認部署是否成功可以訪問(用瀏覽器打開Web App網址會看到這個訊息) function doGet(e) { return ContentService.createTextOutput('NG回報系統運作中,請使用POST方式送出資料。'); }
